Cómo acortar un link

  1. Copiá el link largo que querés compartir y pegalo en el recuadro.
  2. Tocá Acortar link.
  3. Copiá tu link corto de jcads.net y compartilo donde quieras.

Por seguridad, quien abre un link corto ve primero el dominio de destino durante unos segundos antes de continuar. No se aceptan links a contenido para adultos, software malicioso ni otros acortadores, y cada conexión puede crear hasta 20 links por hora.

Preguntas frecuentes

¿Los links cortos vencen?

No tienen fecha de vencimiento. Solo se desactivan si se detecta que llevan a contenido peligroso, engañoso o prohibido.

¿Puedo acortar un link que ya es corto?

No. Para evitar cadenas de redirecciones que esconden el destino real, no se aceptan links de otros acortadores. Pegá el link final.

¿Necesito crear una cuenta?

No hace falta registrarse. Pegás el link, lo acortás y listo.
